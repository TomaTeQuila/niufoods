# Diagramas
- Diagrama de arquitectura
  - Este diagrama representa la arquitectura de la aplicación. Se visualiza el enfoque monolitico que decidí usar, aprovechando las herramientas que otorga Rails para este tipo de arquitecturas, y debido a la simplicidad de la app que espera el cliente.
- Diagramas de bases de datos
  - Diagrama E:R
    - Si bien es similar al diagrama del schema de la bd, este está más simplificado para ver las relaciones, pero al usar la misma app se ven similares. Reminder personal: Re hacerlo en otra aplicación de diagramas para que se vea más a lo esperado
  - Diagrama DB
    - Schema y diagrama de la base de datos, más detallado con sus campos.
- Diagrama de secuencia
  - Diagrama que define la secuencia del flujo principal de la aplicación, más técnico para tener en cuenta a la hora de programar el comportamiento de los distintos componentes y actores que se involucran en el flujo de hacer una orden. Este lo hice para tener más claro las respuestas HTTP que deben tener entre componentes para funcionar, mejorando así la comunicación de estos, y además tener claro el orden de acciones.
